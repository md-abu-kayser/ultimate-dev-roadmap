# Docker & Kubernetes Tools

> Use docker & kubernetes tools to build repeatable engineering workflows.

## What you will learn

- Core concepts and terminology
- How the technology behaves in real applications
- Practical patterns and common mistakes
- Production considerations and trade-offs

## Learning sequence

1. Understand the mental model.
2. Build a tiny example from memory.
3. Build a focused project.
4. Test and debug it.
5. Document the design decisions.

## Production checklist

- [ ] Understand the core concepts
- [ ] Build a small implementation
- [ ] Handle failure cases
- [ ] Add appropriate tests
- [ ] Consider security and performance
- [ ] Explain the trade-offs
