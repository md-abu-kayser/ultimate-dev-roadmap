# System Design Roadmap

## Core dimensions

Correctness, latency, throughput, availability, durability, consistency, security, cost, and operability.

## Framework

```text
Requirements → Constraints → Capacity → API/Data Model → Architecture → Bottlenecks → Scaling → Reliability → Security → Trade-offs
```

## Practice cases

- URL shortener
- Rate limiter
- Notification service
- File storage
- Chat platform
- Search service
- Video processing pipeline
- Payment platform
- Multi-tenant SaaS
