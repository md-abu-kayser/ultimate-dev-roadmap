# Contributing

Thank you for improving the roadmap.

## Good contributions

- New or corrected roadmap topics
- High-quality resources
- Project ideas with realistic requirements
- Better explanations and diagrams
- Broken-link fixes
- Production case studies

## Contribution checklist

- [ ] The change belongs in the correct section.
- [ ] Markdown renders correctly on GitHub.
- [ ] Local links work.
- [ ] Claims are backed by reliable sources where needed.
- [ ] No secrets or private information are included.
- [ ] Duplicate content has been avoided.

## Recommended article structure

```md
# Topic

> Purpose

## Prerequisites
## Mental model
## Core concepts
## Hands-on practice
## Common mistakes
## Production considerations
## Further reading
## Completion checklist
```
